## Overview

MetaMask is the most widely used Ethereum wallet, and its documentation is where developers learn to connect their dapps to it. I contributed from the very beginning, starting with the **documentation prototype** and continuing on the public `metamask-docs` repository for several years.

## The prototype (2019 – 2020)

I merged more than 20 pull requests into the documentation prototype, helping shape what the docs would become:

- Built out the **API reference pages**.
- Created the **API update and release notes page** so developers could track breaking changes.
- **Labeled deprecated APIs** so readers could tell current guidance from legacy behavior at a glance.

## The public docs (2020 – 2023)

More than 20 more merged pull requests on [MetaMask/metamask-docs](https://github.com/MetaMask/metamask-docs):

- Added privacy-friendly **Plausible analytics** to understand how the docs were used.
- Added guidance pointing readers to the **API Playground**, and contributed "Proceed without MetaMask" to the playground itself.
- Ongoing accuracy fixes: broken links, the Watch Token URL, and clarifying the `name` field in `signTypedData_v4`.

## Beyond the docs

The documentation work led to code contributions across the MetaMask ecosystem: the browser extension, the test dapp UI refactor, `etherscan-link` custom network support, and onboarding. I shared what I learned in my ETHDenver talk, *"5 Lessons Learned Contributing to an Ethereum Open Source Project."*
